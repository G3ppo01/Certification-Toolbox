# Certification Toolbox

A collection of tools, scripts, lab exercises, and documentation developed during certification courses and exam preparation.
## Purpose

Capture practical lessons, automate recurring tasks, and keep useful examples in one place for study and future reference.

## Contents

- **Tools & scripts** — utilities and automation created during coursework.
- **Lab exercises** — hands-on scenarios, configuration examples, and walkthroughs.
- **Study notes** — summaries, command references, and troubleshooting tips.
- **Documentation** — setup instructions and lessons learned.

## Organization

Materials are grouped by certification, with dedicated folders for tools, labs, and notes as they are added. For example:

```text
AZ-104/
  tools/
  labs/
  notes/
```

## Getting started

Browse the relevant certification folder and follow the instructions provided with each resource. Prerequisites and usage examples belong alongside the corresponding tool or lab.

This repository grows as I progress through courses and apply what I learn.
